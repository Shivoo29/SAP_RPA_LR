## ⚡ Quick Install (5 Steps)

### Step 1: Extract the ZIP
```
1. Download SAP_RPA_Complete_Project.zip
2. Extract to: C:\SAP_RPA\ (or your preferred location)
3. You should see:
   C:\SAP_RPA\
   ├── main.py
   ├── config.py
   ├── requirements.txt
   ├── setup_check.py
   ├── core\
   ├── transactions\
   ├── workflows\
   ├── data\
   ├── gui\
   └── [10 documentation .md files]
```

### Step 2: Install Python Dependencies
```cmd
cd C:\SAP_RPA
pip install -r requirements.txt
```

**This installs:**
- pandas (Excel operations)
- openpyxl (Excel formatting)
- pywin32 (SAP GUI connection)
- selenium (Web automation for ERF)

### Step 3: Configure Field IDs
```
1. Use your existing sap_field_finder.py
2. Run it and connect to SAP
3. Navigate to MD04 and scan for field IDs
4. Open config.py in a text editor
5. Update the MD04_FIELDS section with your field IDs
6. Example:
   MD04_FIELDS = {
       "material_field": "/app/con[0]/ses[0]/wnd[0]/usr/ctxtRM61R-MATNR",
       "plant_field": "/app/con[0]/ses[0]/wnd[0]/usr/ctxtRM61R-WERKS",
       "mrp_area_field": "/app/con[0]/ses[0]/wnd[0]/usr/ctxtRM61R-BERID",
   }
```

**See FIELD_ID_TEMPLATE.md for detailed instructions!**

### Step 4: Validate Setup
```cmd
python setup_check.py
```

**Fix any issues it reports!**

### Step 5: Launch & Test
```cmd
python main.py
```

1. Click "Connect to SAP"
2. Enter a test material: 857-A65473-106
3. Select plants: 1000
4. Click "Start Automation"
5. Watch it work! 🎉

## 🚨 Important: You MUST Configure

### Before Running, Update in config.py:

1. **Field IDs** (CRITICAL!)
   ```python
   MD04_FIELDS = {
       "material_field": "YOUR_ACTUAL_FIELD_ID",  # Get from field finder
       "plant_field": "YOUR_ACTUAL_FIELD_ID",
       "mrp_area_field": "YOUR_ACTUAL_FIELD_ID",
   }
   ```

2. **Extraction Fields** (CRITICAL!)
   ```python
   EXTRACTION_FIELDS = {
       "Material": "YOUR_ACTUAL_FIELD_ID",        # Get from field finder
       "Part_Description": "YOUR_ACTUAL_FIELD_ID",
       "Recipient": "YOUR_ACTUAL_FIELD_ID",
       # ... etc
   }
   ```

3. **Edge WebDriver Path** (if using ERF Dashboard)
   ```python
   EDGE_DRIVER_PATH = r"c:\Program Files\edgedriver_win64\msedgedriver.exe"
   ```

**Without field IDs, the automation won't work!**

## 💡 Pro Tips

1. **Start Simple**
   - Test with one material first
   - Use only plant 1000 initially
   - Disable fallbacks for first test

2. **Read Logs**
   - Check logs\ folder if issues
   - Logs show exactly what's happening

3. **Use Field Finder**
   - Don't guess field IDs
   - Use your sap_field_finder.py
   - Test each field ID individually

4. **Keep SAP Open**
   - Don't close SAP during automation
   - Don't log out
   - Minimize is OK

## 🆘 Quick Troubleshooting

### "Failed to connect to SAP"
```
→ Is SAP Logon running?
→ Are you logged into SAP?
→ Is SAP GUI Scripting enabled?
```

### "Field not found"
```
→ Update field IDs in config.py
→ Use sap_field_finder.py
→ See FIELD_ID_TEMPLATE.md
```

### "ModuleNotFoundError"
```
→ Run: pip install -r requirements.txt
→ Make sure you're in C:\SAP_RPA\ directory
```

### More Help?
```
→ Read TROUBLESHOOTING.md (50+ solutions!)
→ Run setup_check.py
→ Check logs\ folder
```
